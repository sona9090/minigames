# MiniGames

MiniGames is a project containing a collection of interactive browser mini-games implemented with TypeScript, HTML, and CSS.

## Features

- Interactive browser mini-games
- Responsive layout
- Adaptive design for different screen sizes
- Keyboard and mouse interactions
- Clean and maintainable TypeScript code
- No JavaScript or CSS frameworks

## Technologies

- HTML5
- CSS3
- TypeScript
- Git
- GitHub
